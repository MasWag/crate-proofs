# Specification

The normative independent specification and exhaustive 180-contract API ledger
are in [SPECIFICATION.md](../../../SPECIFICATION.md). Every input value of each
declared source integer type is in scope. The five method families require exact
value preservation, Euclidean low-bit truncation, interval saturation, or exact
checked range membership as appropriate, together with total execution success.

The profile must instantiate those contracts using its recorded extraction target
and actual public dispatchers. Pointer-width generality of the mathematical model
does not widen a single-target checked claim. The extraction pipeline and Aeneas
integer/cast and `Result` models are a trusted translation boundary; generated
Rust bodies and proved application lemmas must not be replaced by application
axioms. Formal coverage and excluded or blocked entries are recorded separately
in results and theorem mappings.
