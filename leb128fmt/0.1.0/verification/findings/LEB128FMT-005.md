# LEB128FMT-005: Formatting model does not expose output or writer failure

## Identity and classification

- Component: Aeneas Lean backend; kind: unsupported-boundary; confidence: source-reviewed; resolution: open.
- Crate/version: leb128fmt/0.1.0; observed: 2026-11-28; upstream report: not-reported; upstream fix: not-checked.
- Inputs: `source.lock.json` and `aeneas/profiles/default/toolchain.lock.json`; Aeneas revision `be86ab0f1989d04944292b345b24c435be3ad10a`, unpatched.

## Expected and observed behavior

The intended `Display` and derived `Debug` obligations include formatted content, formatter state and propagation of writer failure. The generated `DisplayFull.lean` branches on `Error` and calls `Formatter.write_str` with the appropriate literal. The pinned backend's `Aeneas/Std/Core/Fmt.lean` declares `Formatter` as an axiom and models `write_str` as always returning success with the unchanged formatter while ignoring the string. Thus the generated call structure alone does not establish actual output, formatter flags, or propagation of a writer error. The backend also has simplified formatting models; no release bug follows from this model boundary.
