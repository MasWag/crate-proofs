# LEB128FMT-001: Narrow unsigned decoding accepts an out-of-range value

## Identity and classification

- Component: release implementation; kind: implementation-bug; confidence: reproduced-at-pinned-inputs; resolution: open.
- Crate/version: leb128fmt/0.1.0; first observed and last reproduced: 2026-11-28; upstream report: not-reported; upstream fix: not-checked.

## Pinned inputs

`source.lock.json` SHA-256 `de198d9bfda1cf725813d9957bdd96c275cee7885d1b8f0e474be7749b345609`; release archive SHA-256 `09edd9e8b54e49e587e4f6295a7d29c3ea94d469cb40ab8ca70b288248a81db2`; `src/lib.rs` SHA-256 `d3416930498758a653a176d50658540adf1c81cd1e5eade97272b4df69ae92cc`. The example uses `decode_uint_slice::<u8, 1>` with cursor 0 and default features.

## Expected and observed behavior

The unsigned one-bit range is 0–1. `[127]` instead returns `Ok(127)` and advances the cursor to 1. The terminal first byte is returned before the width check; source review shows the same early-return pattern in `decode_uint_arr!`. Only the slice case is reproduced here.

## Reproduction and evidence

`verification/width_observations.rs`, SHA-256 `d7a2fced4a3c0ff0a4517a596d9bc150fb8254824096908a2f46237ea295c857`, records this native observation. A temporary Cargo harness using the unchanged release body reproduced it on 2026-11-28 with `cargo run --offline --manifest-path /private/tmp/leb128-findings/Cargo.toml`, exit 0; the temporary harness is not retained as evidence. The maintained test file is the reproducible source. The maintained tests were run from `leb128fmt/0.1.0` on `aarch64-apple-darwin` with Rust 1.94.1 and the `std` feature, using an existing temporary output directory `t`:

```sh
rustc +1.94.1 --edition=2021 --cfg 'feature="std"' --crate-name leb128fmt --crate-type rlib .work/source/src/lib.rs -o "$t/libleb128fmt.rlib"
rustc +1.94.1 --edition=2021 --test --extern leb128fmt="$t/libleb128fmt.rlib" verification/width_observations.rs -o "$t/widths"
"$t/widths"
```

The test executable exited 0 with three tests passed. Restoring the pinned source and selecting an output directory are required. Native execution is not a formal proof.

## Cause, impact and resolution

The first-byte fast path omits validation against `BITS`, allowing an out-of-range value. The scope of any formal claim must exclude this case unless corrected. No fix or upstream contact is recorded.
