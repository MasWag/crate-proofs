## Expected and observed behavior

The release's explicit `std::error::Error::source` returns `None` for either error variant. Local generated `ErrorSourceFull.lean` translates that body to `ok none`, but its result type contains a dynamic `core.error.Error` trait object. The trait dictionary includes formatting interfaces whose type depends on the backend's axiomatic `core.fmt.Formatter`. The replayed theorem `releaseSourceReturnsNone` has transitive axioms `propext`, `Quot.sound`, and `core.fmt.Formatter`. A reduced result or extracted body alone is not acceptance under an audit excluding the formatter axiom. This is a model/audit boundary, not evidence of a defect in the Rust implementation.
